# Deliverability Checklist

## Checklist

- [ ] Custom sending domain
- [ ] SPF, DKIM, DMARC aligned
- [ ] Gradual warm-up for new domains/IPs
- [ ] Confirmed opt-in / clear consent
- [ ] Regular pruning of hard bounces
- [ ] Monitor complaint rates by provider

See [Ops](/docs/ops) for linked notes and tools.
