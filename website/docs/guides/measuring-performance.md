# Measuring Performance

## Still useful

- Click-through rate and clicked unique links
- Reply rate / qualitative feedback
- Unsubscribe and spam-complaint rates
- Revenue per send / per subscriber

## Noisy

- Open rate (MPP and similar privacy features)

Pair with analytics resources in the README when that section is merged.
