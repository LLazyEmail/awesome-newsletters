# Contributing

This docs site mirrors the curated list in the repository [`README.md`](https://github.com/LLazyEmail/awesome-newsletters/blob/main/README.md).

## Prefer small PRs

1. Keep existing entries — restructure, fix, or annotate gently.
2. One concern per pull request.
3. Use the format: `- [Name](https://example.com) — short description`
4. Alphabetize within a section when practical.

Full guidelines: [`CONTRIBUTING.md`](https://github.com/LLazyEmail/awesome-newsletters/blob/main/CONTRIBUTING.md).

## Suggest a newsletter

Open a PR against `README.md`, or use the **Submit a newsletter or resource** issue form on GitHub.

## Docs regeneration

Some docs pages are generated from the README (`npm run generate:docs-from-readme` in `website/`). After editing the README, regenerate or update the matching docs page in the same PR when practical.
