# Awesome Newsletters website

Docusaurus site for [LLazyEmail/awesome-newsletters](https://github.com/LLazyEmail/awesome-newsletters).

## Scripts

| npm script | Purpose |
| --- | --- |
| `start` | Local dev server |
| `build` | Production build |
| `generate:catalog` | Parse README/docs → `src/data/catalog.json` + `static/api/v1/catalog.json` |
| `generate:notable-newsletters` | Parse notable profiles → `static/api/v1/notable-newsletters.json` |
| `generate:metrics` | Link counts → `static/api/v1/metrics.json` (also runs in `prebuild`) |

## Public JSON API

Served from `static/api/v1/` after build/deploy. The committed copies are refreshed by workflows on `main`:

| File | Regenerated by | When |
| --- | --- | --- |
| `catalog.json` (+ `src/data/catalog.json`) | `catalog-api.yml` | push to `main` touching `README.md` or `website/docs/**` |
| `metrics.json` | `catalog-api.yml` (same commit as the catalog), and `prebuild` on every deploy | same as above |
| `notable-newsletters.json` | `notable-newsletters-api.yml` | push to `main` touching `website/docs/notable-newsletters/**` |

- `/api/v1/catalog.json` — tagged catalog of curated links
- `/api/v1/notable-newsletters.json` — notable newsletter profiles (one entry per profile page; the category's `overview.md` and `index.md` are skipped)
- `/api/v1/glossary.json` — glossary terms
- `/api/v1/metrics.json` — link/doc counts

Pattern mirrors [awesome-email-marketing](https://github.com/LLazyEmail/awesome-email-marketing) industry-leaders + catalog APIs.

## Explore page

`/explore` (`src/components/ResourceFilter`) searches and tag-filters the **whole** catalog. It renders the first 100 matches, then a **Show more** button (100 at a time) and **Show all**. The count line says how many match and how many are shown. Changing the search or tags resets it to the first 100.

## Docs layout

- Top-level docs mirror README sections
- `docs/guides/` — practical publisher guides
- `docs/notable-newsletters/` — per-newsletter study pages
