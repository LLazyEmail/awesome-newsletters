# Contributing to Awesome Newsletters

Thanks for helping curate this list. Prefer **small, focused pull requests** that a maintainer can review in a few minutes.

## Guidelines

1. **Keep existing entries.** Restructure, fix, or annotate gently — do not delete list items wholesale.
2. **One concern per PR.** Examples: add a single resource, fix broken links in one section, tweak CI.
3. **Format.** Use markdown links with a short title and optional one-line description:
   `- [Name](https://example.com) — short description`
4. **Placement.** Add entries under the most relevant section; alphabetize within the section when practical.
5. **No spam / affiliate dumps.** Resources should be useful to newsletter creators or readers.
6. **Draft PRs are welcome** if you want early feedback.

## Suggesting a resource

Open a PR that edits `README.md` (and, once the docs site lands, the matching page under `website/docs/` if applicable). In the PR body, say why the resource belongs here.

## Reporting a broken link

Open an issue or PR. Prefer annotating a dead URL (⚠️ note) over silent deletion until a maintainer confirms.

## Code of conduct

Be respectful. This is a community curation project under [LLazyEmail](https://github.com/LLazyEmail).
